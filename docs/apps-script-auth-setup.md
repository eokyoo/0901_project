# Google 스프레드시트 회원가입·로그인 연결

## 1. Apps Script 코드 설치

1. 사용할 Google 스프레드시트를 엽니다.
2. `확장 프로그램 → Apps Script`를 선택합니다.
3. 기본 `Code.gs` 내용을 모두 지우고 프로젝트의 `google-apps-script/Code.gs` 내용을 붙여넣습니다.
4. Apps Script 편집기에서 `setup` 함수를 선택해 한 번 실행하고 권한을 승인합니다.
5. 스프레드시트에 `Users`, `Sessions` 시트가 생성됐는지 확인합니다.

`Users`에는 사용자 정보와 비밀번호 해시가 저장됩니다. `Sessions`에는 로그인 토큰의 해시와 만료 시각이 저장됩니다. 스프레드시트 공유 설정은 비공개로 유지하세요.

## 2. 웹 앱 배포

1. Apps Script 오른쪽 위 `배포 → 새 배포`를 누릅니다.
2. 유형은 `웹 앱`을 선택합니다.
3. 실행 사용자는 `나`, 액세스 사용자는 블로그 방문자가 접근할 수 있는 항목을 선택합니다.
4. 배포 후 `/exec`로 끝나는 웹 앱 URL을 복사합니다.
5. 프로젝트의 `js/config.js`에서 `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE`를 복사한 URL로 교체합니다.

Apps Script 코드를 수정한 뒤에는 `배포 → 배포 관리 → 수정 → 새 버전`으로 다시 배포해야 변경사항이 반영됩니다. `/dev` 주소는 개발 테스트 전용이므로 블로그에는 `/exec` 주소를 사용하세요.

## 3. 확인 순서

1. `signup.html`에서 테스트 계정을 만듭니다.
2. `Users` 시트에 이메일, 이름, 해시값이 추가됐는지 확인합니다.
3. `login.html`에서 같은 계정으로 로그인합니다.
4. 브라우저 개발자 도구의 콘솔에 오류가 없는지 확인합니다.

## 보안 참고

- 비밀번호 원문은 저장하지 않습니다.
- 서버 비밀값은 Apps Script의 Script Properties에만 저장됩니다.
- 로그인 세션은 7일 후 만료됩니다.
- 이 구조는 개인 블로그·수업용 소규모 프로젝트에 적합합니다. 결제나 민감정보를 다루는 서비스에는 Firebase Authentication 같은 전문 인증 서비스를 사용하세요.
