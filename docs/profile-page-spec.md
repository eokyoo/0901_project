# 개인 프로필 페이지 기획 및 개발 문서

## 1. 프로젝트 개요

HTML, CSS, JavaScript만 사용해 한 페이지 형태의 개인 프로필 웹사이트를 제작한다. 방문자가 프로필 주인의 소개, 기술, 프로젝트, 연락 방법을 쉽고 빠르게 확인할 수 있도록 구성한다.

### 목표

- 개인 소개와 강점을 명확하게 전달한다.
- 주요 기술과 프로젝트를 보기 좋게 보여준다.
- 모바일, 태블릿, 데스크톱에서 자연스럽게 표시되도록 한다.
- 복잡한 프레임워크 없이 기본 웹 기술을 익히며 구현한다.

### 대상 사용자

- 프로필 주인에 대해 알고 싶은 방문자
- 포트폴리오를 확인하는 채용 담당자 또는 협업 파트너
- 연락처와 소셜 링크를 찾는 사용자

## 2. 기술 범위

- HTML5: 페이지 구조와 콘텐츠
- CSS3: 레이아웃, 색상, 반응형 디자인, 애니메이션
- JavaScript: 메뉴, 테마 전환, 스크롤 효과 등 사용자 상호작용
- 외부 프레임워크는 사용하지 않는다.

## 3. 권장 파일 구조

```text
frontend/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
└─ assets/
   ├─ images/
   │  ├─ profile.webp
   │  └─ projects/
   └─ icons/
```

이미지는 용량을 줄인 WebP 형식을 우선 사용한다. 이미지가 준비되지 않은 초기 단계에서는 단색 배경이나 임시 이미지를 사용할 수 있다.

## 4. 페이지 구성

### 4.1 헤더와 내비게이션

- 이름 또는 간단한 로고
- 소개, 기술, 프로젝트, 연락처 섹션으로 이동하는 메뉴
- 모바일 화면에서 열고 닫을 수 있는 햄버거 메뉴
- 선택 기능: 라이트/다크 테마 전환 버튼

### 4.2 메인 소개 영역(Hero)

- 프로필 사진
- 이름과 직무 또는 관심 분야
- 한두 문장의 핵심 소개
- `프로젝트 보기`, `연락하기` 버튼

예시 문구:

> 안녕하세요, 사용자 경험을 중요하게 생각하는 웹 개발자 홍길동입니다.

### 4.3 자기소개(About)

- 간단한 소개와 경력 또는 관심 분야
- 현재 배우거나 집중하는 내용
- 거주 지역 등 공개 가능한 기본 정보
- 이력서가 있다면 다운로드 링크 제공

### 4.4 기술(Skills)

- HTML, CSS, JavaScript 등 보유 기술
- 기술을 카테고리별로 분류
- 숙련도를 과장하기 쉬운 퍼센트 대신 실제 사용 경험이나 수준을 텍스트로 표현

예시:

- Frontend: HTML, CSS, JavaScript
- Tools: Git, GitHub, VS Code
- Currently Learning: React, TypeScript

### 4.5 프로젝트(Projects)

각 프로젝트 카드는 다음 정보를 포함한다.

- 대표 이미지
- 프로젝트 이름
- 한두 문장의 설명
- 사용 기술
- 데모 링크와 저장소 링크

최소 2개에서 3개의 프로젝트를 노출하며, 링크가 없다면 버튼을 표시하지 않는다.

### 4.6 연락처(Contact)

- 이메일 주소
- GitHub, LinkedIn, 블로그 등 소셜 링크
- 선택 기능: 이름, 이메일, 메시지를 입력하는 연락 폼

정적 페이지에서는 서버 없이 폼을 전송할 수 없으므로 초기 버전은 `mailto:` 링크나 이메일 복사 버튼을 권장한다. 실제 폼 전송이 필요하면 이후 백엔드 API 또는 외부 폼 서비스를 연결한다.

### 4.7 푸터

- 저작권 문구
- 현재 연도를 JavaScript로 자동 표시
- 페이지 상단으로 이동하는 링크

## 5. 디자인 가이드

### 시각 방향

- 깔끔하고 여백이 충분한 단일 페이지 디자인
- 강조 색상은 한 가지를 중심으로 사용
- 카드, 버튼, 링크의 모양과 간격을 일관되게 유지
- 본문이 배경과 충분한 명암 대비를 갖도록 구성

### 권장 CSS 변수

```css
:root {
  --color-background: #f8fafc;
  --color-surface: #ffffff;
  --color-text: #172033;
  --color-text-muted: #64748b;
  --color-primary: #4f46e5;
  --color-border: #e2e8f0;
  --content-width: 1120px;
  --radius: 16px;
  --shadow: 0 12px 30px rgb(15 23 42 / 8%);
}
```

### 반응형 기준

- 모바일: 767px 이하
- 태블릿: 768px~1023px
- 데스크톱: 1024px 이상

모바일 우선으로 CSS를 작성하고 화면이 넓어질 때 레이아웃을 확장한다. 프로젝트 카드는 모바일에서 한 열, 태블릿에서 두 열, 넓은 화면에서 최대 세 열로 배치한다.

## 6. JavaScript 기능

### 필수 기능

1. 모바일 메뉴 열기와 닫기
2. 내비게이션 클릭 시 해당 섹션으로 부드럽게 이동
3. 현재 연도를 푸터에 자동 표시
4. 이메일 복사 버튼과 복사 완료 안내

### 선택 기능

1. 라이트/다크 테마 전환과 `localStorage`를 이용한 설정 저장
2. 스크롤 위치에 따른 현재 메뉴 강조
3. 요소가 화면에 나타날 때 가벼운 등장 효과
4. 프로젝트 카테고리 필터

동작이 실패해도 주요 콘텐츠를 읽고 링크를 이용할 수 있도록 HTML 기본 기능을 우선한다.

## 7. HTML 구조 예시

```html
<body>
  <header>...</header>
  <main>
    <section id="home">...</section>
    <section id="about">...</section>
    <section id="skills">...</section>
    <section id="projects">...</section>
    <section id="contact">...</section>
  </main>
  <footer>...</footer>
  <script src="js/main.js" defer></script>
</body>
```

`header`, `nav`, `main`, `section`, `article`, `footer` 같은 시맨틱 태그를 사용한다. 제목은 `h1`부터 순서를 지키며, 한 페이지의 `h1`은 프로필 이름에 한 번만 사용한다.

## 8. 접근성과 사용성

- 모든 이미지에 내용을 설명하는 `alt`를 작성한다.
- 아이콘만 있는 버튼에는 `aria-label`을 제공한다.
- 키보드만으로 메뉴, 버튼, 링크를 사용할 수 있어야 한다.
- 포커스 표시를 제거하지 않고 눈에 잘 보이도록 디자인한다.
- 색상만으로 상태나 의미를 전달하지 않는다.
- 링크가 새 창에서 열리면 사용자에게 알리고 `rel="noopener noreferrer"`를 사용한다.
- 애니메이션은 `prefers-reduced-motion` 설정을 존중한다.

## 9. 콘텐츠 준비 목록

개발 전에 다음 내용을 준비한다.

- [ ] 표시할 이름
- [ ] 직무 또는 한 줄 소개
- [ ] 자기소개 문장
- [ ] 프로필 사진
- [ ] 보유 기술 목록
- [ ] 프로젝트별 이름, 설명, 이미지, 사용 기술, 링크
- [ ] 공개할 이메일 주소
- [ ] GitHub 및 기타 소셜 링크
- [ ] 이력서 파일 또는 링크(선택)

개인 전화번호, 상세 주소 등 민감한 개인정보는 공개 저장소와 웹페이지에 넣지 않는다.

## 10. 구현 순서

1. `frontend`에 권장 파일과 폴더 구조를 만든다.
2. HTML에 전체 섹션과 실제 콘텐츠를 작성한다.
3. CSS 변수, 기본 글꼴, 여백과 색상 체계를 정의한다.
4. 모바일 레이아웃을 먼저 구현한다.
5. 미디어 쿼리로 태블릿과 데스크톱 레이아웃을 추가한다.
6. JavaScript 필수 기능을 구현한다.
7. 선택 기능을 하나씩 추가한다.
8. 키보드 조작, 링크, 반응형 화면과 브라우저 콘솔 오류를 점검한다.

## 11. 완료 기준

- [ ] 소개, 기술, 프로젝트, 연락처 섹션이 모두 표시된다.
- [ ] 내비게이션 링크가 올바른 섹션으로 이동한다.
- [ ] 320px 너비의 모바일 화면에서 가로 스크롤이 발생하지 않는다.
- [ ] 데스크톱 화면에서 콘텐츠가 지나치게 넓어지지 않는다.
- [ ] 모든 이미지와 외부 링크가 정상적으로 동작한다.
- [ ] 키보드로 모든 대화형 요소를 사용할 수 있다.
- [ ] 브라우저 개발자 도구 콘솔에 오류가 없다.
- [ ] HTML, CSS, JavaScript가 역할별 파일로 분리되어 있다.
